DATA PROVENANCE

What is sourced, what is modeled

Nearby weather
Fetching nearby weather from Open-Meteo. Surface values represent a forecast grid point near the storm center, not a cyclone advisory.

Satellite backdrop
NASA Blue Marble forms the continuous Earth base. Previous-day MODIS observations appear where satellite swaths exist; missing swaths reveal the base image.

Physics and impact
Python computes a Holland-type wind profile and sparse Open-Meteo global wind/current vectors. The 72-hour path and economic sensitivity are scenarios, not forecasts.
